# QuartzWrt App

QuartzWrt 专属移动端（Flutter）：局域网 mDNS 自动发现、安全配对、状态展示与白名单设备控制，经 Tailscale/ZeroTier 远程管理。

**当前状态**: 设计讨论（设计规范见 [`docs/DESIGN.md`](docs/DESIGN.md)，讨论稿 v0.1，待拍板十项决策）。
**依赖**: 路由器侧 `quartz-app-api`（WP-5）+ `quartz-daemon`（WP-4）；数据契约 `AGGREGATE-API v1`（与 Dashboard 同源）。
